# Python E-Commerce System

A console-based e-commerce application built with Python using Object-Oriented Programming (OOP).

## Features
- View available products
- Add and remove products from a shopping cart
- Update product quantities
- Checkout and generate receipts
- Cancel orders
- View order history
- Manage inventory

## Technologies
- Python 3
- Object-Oriented Programming (OOP)

## How to Run

1. Download the repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

## Project Structure
- `main.py` — Application entry point
- `store.py` — Store interface and menu
- `product.py` — Product class
- `inventory.py` — Inventory management
- `order.py` — Shopping cart and order processing
